    BeStMeta Metadata Schema

    A cross-domain metadata schema for video tracking assays (VTAs) with focus on ecotoxicology and biomedical research. Designed to improve FAIR compliance by providing structured, machine-readable metadata for VTA datasets and individual trials.

    URI: https://w3id.org/bestmeta/schema

    Name: bestmeta

    Classes

    Class Description
    Acquisition Video acquisition and recording parameters, including timing encoding and illumination details.
    DeviceTypeMixin Reusable slot bundle providing device_type, allowing multiple classes (e.g. Hardware, TrackingAnalysis) to independently branch their validation rules based on the type of imaging system used, without requiring cross-class rule evaluation.
    EnvironmentalConditions Environmental conditions and husbandry parameters for the experiments.
    Experiment Defines experimental context in which the subjects were studied. Covers environmental parameters like study counts, arena geometry, temperature, multi well plate details etc.
    ExperimentalConditions Biological and experimental conditions applicable to all trials in the dataset. Covers organism identity, treatment, assay design, and environmental parameters.
    Hardware Camera systems, optical configuration, and physical recording infrastructure used in the VTA. Documents instrument identity and optical specifications.
    HardwareandAcquisition Defines video hardware configuration (camera or microscope) and acquisiiton or recording parameters used during experiments.
    Manipulation Treatment and chemical exposure information decribing pharmacological, toxicological and/or any other interventions that subjects went through. This sub-class can be omitted where no interventions were used.
    StatisticalAnalysis Information describing the statistical analysis of behavioral data, including statistical tests, models, significance criteria, multiple-testing corrections, and other methods used to evaluate experimental outcomes.
    Subject Biological identity of the organism(s) that is studied. Contains details like taxonomy, strain, genotype, sex, age and/or other morphometric details and measurements.
    TrackingAnalysis Tracking software identity and version, algorithm details, post-tracking computational steps and derived behavioral metrics.
    VTADataset Top-level study and provenance metadata for a VTA dataset. One record per publication or deposited dataset. Contains identifying, licensing, and bibliographic information.

    Slot Description
    acquisition Acquisition/recording parameters for the video.
    acquisition_notes Free-text notes on acquisition settings
    age_unit Age unit of the tracked organism(s).
    age_value Numeric age value of the tracked organism(s).
    analysis_code_doi DOI of the deposited analysis code.

    arena_height Height of the arena, when applicable.
    arena_height_unit Unit of measurement for the height of the arena.
    arena_length Length of the arena along one axis.
    arena_length_unit Unit of measurement for the length of the arena.
    arena_shape Geometric shape of the test arena.
    arena_type Type of the test arena, e.g., open field, multiwell plate or elevated plus maze.
    arena_width Width of the arena along one axis.
    arena_width_unit Unit of measurement for the width of the arena.
    assay_description Free-text description of the assay protocol
    assay_type Name of the behavioral assay paradigm or test paradigm.
    behavioral_metrics List of behavioral metrics or endpoints extracted from tracking data.
    bit_depth Bit depth per pixel channel of the recorded video.
    body_length_unit Body length unit of the tracked organism(s).
    body_length_value Body length numeric value of the tracked organism(s).
    camera_count Number of cameras used simultaneously.
    camera_distance Distance from camera lens to the arena floor.
    camera_distance_unit Unit of measurement for camera distance.
    camera_interface Interface standard used for communication between the camera and the acquisition system.
    camera_manufacturer Manufacturer of the camera.
    camera_model Full manufacturer model name of the camera.
    camera_position Position of the camera relative to the arena.
    camera_sensor_type Image sensor technology.
    camera_type General type of imaging device.
    closed_box_system_name Name of the integrated commercial closed-box tracking system. (e.g. ZebraBox, DanioVision, ToxMate, PhenoTyper).
    closed_box_system_version Hardware version or model number of the closed-box system.
    color_mode Color mode of the recorded video. Affects tracking algorithm behavior and file size.
    compute_hardware Primary compute hardware used for tracking and analysis. Include model information when available.
    confidence_interval_level Confidence interval reported for statistical results.
    contrast_polarity Contrast relationship between the tracked object and the background; indicates whether the subject appears bright on a dark background or dark on a bright background in the recorded video.
    control_type Type of control group used.
    dataset_contact_email Contact email for the dataset maintainer.
    dataset_created_date Date when the dataset was created (YYYY-MM-DD)
    dataset_creator_name Name(s) of data creators.
    dataset_creator_orcid ORCID identifier of the dataset creator.
    dataset_description Free-text description of the dataset and its scientific purpose
    dataset_doi DOI of the deposited dataset (assigned by repository)
    dataset_id Unique identifier for the dataset or study package.
    dataset_license SPDX license identifier or URL (e.g. CC-BY-4.0)
    dataset_notes Free-text notes on the dataset not captured by structured fields.
    dataset_title Descriptive title of the dataset.
    dataset_version Semantic version string for the dataset (e.g. 1.0.0)
    developmental_stage Developmental stage of the tracked organism(s).
    developmental_stage_unit Unit for developmental stage value of the tracked organism(s).
    developmental_stage_value Numeric developmental stage value (e.g. 72 for 72 hpf) of the tracked organism(s).
    device_type Indicates the category of imaging system used; determines which additional hardware or tracking fields are required or recommended.
    dropped_frames_count Number of video frames lost or omitted during acquisition.
    dropped_frames_reason Reason for dropped or omitted frames during acquisition, recording, encoding, or quality control.
    effect_size_measure Effect size measure reported to quantify the magnitude of observed effects or associations.
    endpoint_definitions Definitions and calculation criteria used for behavioral endpoints, including thresholds, zone boundaries, event definitions, and other parameters required to reproduce endpoint calculations.
    environmental_conditions Environmental conditions during the experiment, including water chemistry, feed, and other details.
    experiment The experimental setup and environment for this dataset's trials.
    experiment_end_datetime Date and time at which the experiment ended.
    experiment_notes Free-text notes on the overall experimental conditions.
    experiment_start_datetime Date and time at which the experiment began.
    experimental_conditions Biological and experimental conditions for this dataset
    exposure_compound_chebi_id ChEBI identifier for the test substance.
    exposure_compound_name Name of the chemical, drug, or substance used in the treatment or exposure.
    exposure_concentration Nominal exposure concentration (numeric value only; use unit field).
    exposure_concentration_unit Unit for exposure concentration.
    exposure_duration Duration of chemical or treatment exposure in hours.
    exposure_duration_unit Unit of measurement used to report exposure duration.
    exposure_route Route of chemical or treatment administration.
    exposure_time Camera sensor exposure time per frame.
    exposure_type It indicates the type of exposure (Acute or chronic)
    feed_type Type of feed provided to the subject(s).
    field_of_view_height Numeric value of vertical field of view covered by the camera.
    field_of_view_unit Unit of measurement for field_of_view_width and field_of_view_height.
    field_of_view_width Numeric value of horizontal field of view covered by the camera.
    frame_rate Number of frames captured per second (fps) during video recording.
    frames_without_tracked_bodypart Percentage of frames in which no body part was tracked.
    frames_without_tracked_individual Percentage of frames in which no individual was tracked.
    gain Camera gain setting at the time of recording.
    genotype Genotype identifier of the tracked organism(s) including strain-specific, mutant, transgenic, or engineered genotypes.
    habituation_duration Duration of habituation period before recording.
    habituation_duration_unit Unit of measurement used to measure habituation duration
    habituation_protocol Description of habituation or acclimation prior to testing.
    hardware Hardware configuration used to record the video.
    hardware_acquisition_notes Free-text catch-all for additional context about the hardware and acquisition setup as a whole that does not fit within hardware_notes or acquisition_notes specifically (e.g. deviations from standard protocol, or setup issues spanning both hardware and acquisition).
    hardware_and_acquisition Hardware and acquisition configuration used to record the video dataset.
    hardware_notes Free-text notes on hardware configuration not captured by structured fields.
    housing_conditions Free-text description of animal housing conditions prior to assay.
    humidity Relative humidity where experiment was conducted (or the experiment area).
    illumination_illuminance Illuminance at the recording arena or observation surface.
    illumination_type Type of illumination used during recording.
    illumination_wavelength Peak wavelength of the illumination source in nanometres. Use for non-white-light sources such as infrared or UV.
    in_house_system_components List of key hardware components used in the custom-built system (e.g. camera sensor, lens, illumination source, mounting hardware).
    in_house_system_description Free-text description of the custom-built imaging system, including how the components are assembled and used.
    in_house_system_designer Lab, person, or institution that designed or built the in-house system.
    lens_focal_length Focal length of the imaging lens in millimetres; applicable to camera or microscope optics when reported.
    lens_focal_length_unit Unit of measurement for focal length of lens (microscope)
    light_cycle_detail Free-text description of the light-dark cycle.
    light_cycle_type Standardized category of the light-dark cycle.
    manipulation Any intervention applied to the subjects. Omitted when no treatment or exposure was used.
    microscope_lot_number Lot number of the microscope.
    microscope_manufacturer Manufacturer of the microscope.
    microscope_model Model name or identifier of the microscope.
    microscope_serial_number Serial number of the microscope.
    microscope_type Microscope configuration according to the OME microscope type classification.
    mortality Indicates whether a subject died during the course of the experiment.
    mortality_notes Free-test notes on any deaths that occured during the trial. This can be used to provide additional context about mortality.
    multiple_testing_correction Procedure used to correct for multiple comparisons (if more than one hypothesis was tested). Include the name of the method and any parameters (e.g., false‑discovery‑rate level).
    n_bodyparts_tracked Number of body parts or keypoints tracked per individual.
    n_individuals_end Number of individuals at the end of the experiment/trial.
    n_individuals_per_arena Number of individuals tested simultaneously in the arena.
    n_individuals_represented Represents the toal number of individual subjects in a given subject entry. Use a value greater than one to show its a homogenous subjects. Defaults to one (when omitted)
    n_individuals_start Number of individuals at the start of the experiment/trial.
    n_individuals_total Total number of individuals used in the experiment.
    n_individuals_tracked_per_arena Number of individuals actually tracked in a single arena or trial.
    noise_reduction_method Method or algorithm used to reduce image noise during acquisition or immediately after recording.
    objective_magnification Magnification of microscope objective (if applicable).
    plate_well_count Number of wells in the multiwell plate.
    preprocessing_steps Preprocessing steps applied to video before tracking to enhance quality or isolate features.
    publication_doi DOI of the publication associated with the dataset.
    raw_data_repository Repository where raw tracking data and/or video files are deposited.
    raw_data_repository_url URL of the repository record or landing page.
    raw_tracking_data_doi DOI of the deposited raw tracking data
    raw_tracking_data_format File format of the raw tracking data.
    recording_duration Total duration of the video recording in ISO 8601 duration format.
    recording_end_datetime Date and time at which acquisition of the video recording ended.
    recording_software_name Name of the software used to record the video.
    recording_software_version Version string of the recording software.
    recording_start_datetime Date and time at which acquisition of the video recording began.
    research_domain Primary research domain of this study.
    sample_size_analysis Sample size or power analysis method, software, or justification used before the study.
    sex Biological sex of the tracked organism(s).
    significance_level Significance threshold used for hypothesis testing (e.g., alpha).
    solvent_vehicle Solvent or vehicle used to dissolve the test substance.
    spatial_resolution Physical size represented by one pixel at the observation plane.
    species_name Scientific (Latin) binomial name of the study organism
    species_ncbi_taxon_id NCBI Taxonomy ID for the study organism
    statistical_analysis Statistical analysis for this dataset
    statistical_models Statistical models used to analyse behavioral endpoints.
    statistical_software_name Name of the software used for statistical analysis.
    statistical_software_version Version string of the software used for statistical analysis.
    statistical_tests Statistical tests applied to behavioral endpoints for hypothesis testing or inference.
    statistics_notes Free-text notes on the statistical analysis not captured by structured fields.
    strain Organism strain or line
    subject Indicates if a single animals or multiple animals are used, it could be 1 for single-animal models or well plate studies, >1 for multi-animal rodent studies
    subject_colour Indicates the colour of the subject. This is useful for tracking.
    subject_type Indicates whether the subject being tracked is a whole organism or a cell/cell culture; determines which biological identity fields are applicable.
    subjects_per_field_of_view Number of individual subjects (e.g. wells, organisms, larvae) visible within a single field of view or camera frame, when applicable.
    total_frame_count Total number of frames in the video. Can be derived from frame_rate × recording_duration if not explicitly stated.
    tracking_algorithm Algorithmic approach used to detect, identify, and track organisms in video recordings. Multiple values may be provided when tracking is performed using a pipeline of methods.
    tracking_analysis Tracking software and analysis configuration
    tracking_confidence_threshold Confidence or likelihood threshold used to accept detections, identities, tracks, or keypoints during tracking analysis.
    tracking_data_format File format used to store tracking results, including coordinates, keypoints, identities, trajectories, annotations, or derived outputs.
    tracking_manual_correction Whether tracking results were manually reviewed, corrected, or curated after automated tracking.
    tracking_notes Free-text notes on the tracking analysis not captured by structured fields.
    tracking_software_name Name of the software used for tracking.
    tracking_software_settings Key tracking configuration parameters used during analysis, including software-specific settings required to reproduce tracking results.
    tracking_software_type Indicates whether the tracking analysis was performed using a custom software or a standard package or software
    tracking_software_version Version string of the tracking software.
    treatment_description Full description of the treatment protocol.
    treatment_name Short label identifying the experimental treatment group, condition, or regimen.
    video_codec Video compression codec used for recording.
    video_container_format File container format of the recorded video.
    video_resolution_height Vertical pixel count of the recorded video.
    video_resolution_width Horizontal pixel count of the recorded video.
    water_depth The depth of the water used for aquatic essays
    water_depth_unit Unit of measurement for the depth of water
    water_ph pH of the water in housing/experimnetal conditions
    water_temperature The temperature of the water during the experiment
    water_temperature_unit The unit of the water temperature.
    weight_unit Body weight unit of the tracked organism(s).
    weight_value Body weight numeric value of the tracked organism(s).
    well_plate_format Format of the multi-well plate used in a closed-box imaging system (e.g. "96-well", "24-well"), when applicable.
    well_shape_bottom Geometric bottom shape of the wells of a multiwell plate.
    well_shape_cross_section Geometric cross section shape of the wells of a multiwell plate.

    WellCrossSectionShapeEnum Geometric cross section shape of the wells of a multiwell plate.
    WellPlateFormatEnum Type of well plate used in a closed box system.

    Types

    Type Description
    Boolean A binary (true or false) value

    Date a date (year, month and day) in an idealized calendar

    Datetime The combination of a date and time
    Decimal A real number with arbitrary precision that conforms to the xsd:decimal specification
    Double A real number that conforms to the xsd:double specification
    Duration A time duration in ISO 8601 format
    Float A real number that conforms to the xsd:float specification
    Integer An integer
    Jsonpath A string encoding a JSON Path. The value of the string MUST conform to JSON Point syntax and SHOULD dereference to zero or more valid objects within the current instance document when encoded in tree form.
    Jsonpointer A string encoding a JSON Pointer. The value of the string MUST conform to JSON Point syntax and SHOULD dereference to a valid object within the current instance document when encoded in tree form.
    Ncname Prefix part of CURIE
    Nodeidentifier A URI, CURIE or BNODE that represents a node in a model.
    Objectidentifier A URI or CURIE that represents an object in the model.
    Sparqlpath A string encoding a SPARQL Property Path. The value of the string MUST conform to SPARQL syntax and SHOULD dereference to zero or more valid objects within the current instance document when encoded as RDF.
    String A character string
    Time A time object represents a (local) time of day, independent of any particular day
    Uri a complete URI
    Uriorcurie a URI or a CURIE
